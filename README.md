
# 🛒 বাজার দর | BazarDor

### Your Smart Online Marketplace

**বাজার দর (BazarDor)** একটি আধুনিক ও ব্যবহারবান্ধব অনলাইন মার্কেটপ্লেস, যেখানে ব্যবহারকারীরা সহজে বিভিন্ন পণ্য দেখতে, প্রয়োজনীয় পণ্য খুঁজে পেতে এবং নিজেদের অ্যাকাউন্ট পরিচালনা করতে পারবেন। সহজ নেভিগেশন, রেসপনসিভ ডিজাইন এবং নিরাপদ ব্যবহারকারী ব্যবস্থাপনার মাধ্যমে কেনাকাটার অভিজ্ঞতাকে আরও সহজ করাই এই প্রজেক্টের লক্ষ্য।

---

## ✨ মূল ফিচারসমূহ

- **🛍️ পণ্য ব্রাউজিং:** বিভিন্ন ক্যাটাগরির পণ্য দেখা এবং প্রয়োজনীয় পণ্য খুঁজে নেওয়া।
- **📂 ক্যাটাগরি নেভিগেশন:** ক্যাটাগরি অনুযায়ী পণ্য খুঁজে পাওয়ার সহজ ব্যবস্থা।
- **🔐 ব্যবহারকারী প্রমাণীকরণ:** সাইন আপ, সাইন ইন এবং নিরাপদ অ্যাকাউন্ট ব্যবস্থাপনা।
- **👤 প্রোফাইল ব্যবস্থাপনা:** নিজের প্রোফাইল দেখা এবং ব্যক্তিগত তথ্য আপডেট করা।
- **📱 রেসপনসিভ ডিজাইন:** মোবাইল, ট্যাবলেট ও ডেস্কটপে ব্যবহার উপযোগী আধুনিক ইন্টারফেস।

## 🚀 লোকাল মেশিনে চালানোর নিয়ম

### ১. রিপোজিটরি ক্লোন করো

```bash
git clone https://github.com/abirjuboraj/b14-Bazar-Dor
```

### ২. প্রজেক্ট ফোল্ডারে প্রবেশ করো

```bash
cd bazardor
```

### ৩. প্রয়োজনীয় প্যাকেজ ইনস্টল করো

```bash
npm install
```

### ৪. এনভায়রনমেন্ট ভেরিয়েবল সেট করো

প্রজেক্টের প্রয়োজনীয় ডেটাবেজ ও Better Auth কনফিগারেশনসহ `.env.local` ফাইল তৈরি করো।

### ৫. ডেভেলপমেন্ট সার্ভার চালু করো

```bash
npm run dev
```

এরপর ব্রাউজারে [http://localhost:3000](http://localhost:3000) ভিজিট করো।
